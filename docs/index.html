The actual failure mode

Correction without revision becomes instruction debt.

Coding agents are good at recording a new exception after a failure. They are much less likely to revisit the rule that caused it. Over time, the core decision disappears beneath branches that were each reasonable in isolation.

Opinionated by design

History informs the decision. It does not own it.

01

Temporal, not disposable

Recency is a decay weight, never an age cutoff. Older evidence stays available as support, conflict, or context.

02

Authority before confidence

An explicit user reversal outranks a newer assistant summary. Scope, source, and supersession remain separate signals.

03

Total disposition

The model must keep, replace, remove, or relocate every existing directive exactly once. It cannot silently drop inconvenient rules.

04

Evidence, not vibes

User interaction logs and optional Kindex entries affect vitality only through locally minted IDs, bounded quotes, and deterministic counts.

A controlled state transition

The model proposes. Local code decides what is admissible.

1

Read

Instruction targets, prompt indexes, opt-in histories, auto-memory, and active Kindex knowledge.

→
2

Stream, deduplicate, redact locally, preserve temporal breadth, and fit a hard token budget.

→
3

Send current directive text and selected, locally redacted evidence to one pinned Anthropic model for exact operations.

→
4

Verify

Reject unknown IDs, invented quotes, unresolved conflicts, excessive churn, drift, or secrets.

→
5

Archive + apply

Bind approval to the plan hash, archive pre/post images, write atomically, and keep restoration exact.

What Meditate does not claim to clean

Model weights, hidden provider state, retrieval databases, dirty worktrees, tool-side effects, and arbitrary agent-platform memory are outside its boundary. Meditate targets instruction files and learned behavioral directives—the local state its operator can inspect and recover.

Recovery is a product feature

A rewrite is not valid unless it can be explained and undone.

Meditate treats model output as untrusted input. Filesystem paths come from a local allowlist, plan IDs are minted locally, and apply refuses to guess through drift or an interrupted transaction.

Read the privacy boundary →
A

Archive before write

SHA-256-addressed pre-images, post-images, manifests, modes, and receipts live in a private local state directory.

B

Fail closed

Secret matches, degraded parsing, source drift, malformed output, ambiguity, and budget exhaustion block mutation.

C

Exact approval

Attended apply requires the proposal’s exact SHA-256. A report or run identifier is not ambient authority.

D

Restore without erasure

Later hand edits block restore unless forced; forced restore archives those diverged bytes before replacement.

Get started

Inspect first. Apply only after reading the report.

Meditate is currently an alpha source distribution. Clone the repository, install it in an isolated environment, and initialize a commented local configuration.

shell 
git clone https://github.com/jmcentire/meditate.git
cd meditate
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/meditate init
.venv/bin/meditate inspect
