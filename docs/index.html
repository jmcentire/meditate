v0.5.0 alpha · Direct targets · Reversible execution

Rewrite the rule.
Not another exception.

Authority before confidence. A fluent rewrite has no authority of its own; current instructions, explicit corrections, scope, and handoff boundaries come first.

Meditate is a behavioral-contract compiler and policy router for the directives Claude Code and Codex load. Version 0.5 joins evidence-grounded semantic nomination and bounded directive compilation to archive-first reversible execution. It reviews current prose with temporal interactions and Kindex—an optional local persistent knowledge graph exposed through kin—for contradiction, supersession, under/over-specification, wrong scope, enforcement candidates, and missing rules. Evidence-grounded missing rules can become reversible introductions. A well-formed file is a byte-identical no-op. Safe plans apply after exact archive/hash/drift checks and print their restore command; consequential plans require exact attended approval. Repeatable --target inputs can now be maintained in place or compiled into one explicit --output without changing persistent configuration.

The actual failure mode

Correction without revision becomes instruction debt.

Coding agents are good at recording a new exception after a failure. They are much less likely to revisit the rule that caused it. Over time, the core decision disappears beneath branches that were each reasonable in isolation.

Illustration, not behavioral-equivalence proof

This exact-duplicate example shows the typed output shape. It does not prove that a boundary example is executable or that an arbitrary rewrite preserves behavior. An optional owner-authored consumer-agent suite adds bounded behavioral evidence.

Opinionated by design

History informs the decision. It does not own it.

01

Authority before confidence

An explicit user reversal outranks a newer assistant summary. Scope, source, and supersession remain separate signals.

02

Temporal, not disposable

Recency is a decay weight, never an age cutoff. Older evidence stays available as support, conflict, or context.

03

Total disposition, bounded model access

Every source record is kept, replaced, removed, relocated, or escalated exactly once. The model sees only locally detected candidates; unrelated records are kept byte-for-byte.

04

Kindex means required

When enabled and installed, every configured Kindex read must succeed. Failure is kindex_required_failed; durable evidence is never silently dropped to manufacture a plan.

Scope and loaded state are part of the contract

Specific context stays specific.

Contextual guidance relocates only into an exact configured Claude rule with a non-empty paths: list. Meditate never invents a glob or averages separate contexts into vague prose. Every change copies its destination literally from allowed_targets: target strings are opaque, so ~ is never expanded and paths are never normalized, absolutized, or invented. Non-relocates copy the source target; relocation chooses another exact configured target.

Five dispositions

Keep, replace, remove, relocate, or escalate. Source-only removal is limited to a locally confirmed exact duplicate while an identical peer remains byte-for-byte. Escalate preserves source bytes, requires independent evidence, and only reports a hook/settings candidate.

Import integrity

Claude @path graphs are validated to four hops and bound before/after. Imported documents are sanitized read-only context, never implicit targets.

Product metrics

Reports persist pre/post directive, UTF-8 byte, and line totals and deltas; escalations remain separate from changed directives and churn.

Honest budgets

Claude's 200-line status is guidance, not a hard limit. Configured Codex targets are checked against project_doc_max_bytes with configured-only coverage.

Import trust boundary

Meditate faithfully follows configured Claude roots' documented relative, absolute, and ~/ @path imports. Operators must trust those roots and graphs: an import may read any process-readable file it names. Import-only documents are submitted as immutable context and cannot be written through their import role. Recognized secret shapes in imported content are redacted locally before provider submission, but pattern redaction is not comprehensive and is not a filesystem sandbox. Same-user filesystem compromise is outside Meditate's threat boundary.

A controlled state transition

The model proposes. Local code decides what is admissible.

One file in place, many files in place, or many into one

--target FILE may be supplied more than once on inspect, plan, and run. Without --output, each input is planned jointly and rendered back to its own path, with its own exact backup. With --output FILE, every input is read-only and only that file may change. The output may also be one input: combining AGENTS.md and CLAUDE.md back into AGENTS.md archives the original AGENTS file and leaves CLAUDE unchanged. 

meditate run --target ./AGENTS.md --target ./CLAUDE.md \
  --output ./AGENTS.md --apply

Input order, hashes, source paths, the one writable output, and its physical pre-image are plan-bound and drift-checked. Output-as-input frontmatter wins; otherwise the first target supplies the YAML envelope. Secondary envelopes are reported by an explicit non-blocking warning, not merged. Any drift aborts before the first write. meditate restore RUN_ID recovers an old output or removes one that was newly created.

Repeating output-as-input does not append an unchanged source forever: a secondary document is recorded and omitted only when every directive already exists in the output with the same raw bytes and heading path. Similar prose is never assumed equal.

Workflow order is repository-defined; verification is stage-local

Cited action lists establish coverage, never universal order. High-impact proposals must follow the exact loaded repository and documented workflow order. Before each action, only checks that are applicable, project-required, and available before that action may be required. Push-, PR-, and merge-triggered CI, approvals, and named handoffs are each evaluated at their own stage, where they exist. Requiring all CI before commit is forbidden. That unsafe universal gate is rejected in every replacement or relocation, even when its remote actions already existed. Restored-baseline run 20260818T231558Z-6e8e4703 was rejected and not applied for violating this rule. Release review caught what the prior validator admitted; the run is now a regression fixture the current gate must reject, not behavioral qualification.

The fixed point is stability, not shrinkage

Analyst prompt v5 (SHA-256 307102f5...)/parser v6 and Drafter prompt v18 (SHA-256 510c166f...)/parser v34 optimize defect resolution in this order: correctness, checkability, scope precision, then concision. Byte counts are telemetry, never the objective. A justified rationale may make a directive larger. Removing a directive requires a cited ground; “reduce count” is not one.

exact_duplicate is a confirmed local defect. exception_lineage is only a review candidate: lexical overlap cannot declare otherwise-valid prose wrong. A changed post-image that retains a confirmed defect is rejected as non_idempotent_proposal; a review candidate may remain when the planner correctly keeps it.

Acceptance is executable: a well-formed fixture remains byte-identical, a defective fixture is corrected, both results survive a second invocation, ten iterations over the well-formed fixture do not drift (the first analysis is cached and exact repeats use no provider call), and every confirmed cluster in a multi-defect fixture must resolve in one successful plan.

Every directive Meditate introduces or materially rewrites carries one meaningful RFC 2119 operator—MUST, MUST NOT, SHOULD, SHOULD NOT, or MAY—plus a reason and scope. ALWAYS compiles to MUST, NEVER to MUST NOT, and ambiguous MAY NOT is excluded. Valid legacy prose is not churned merely to add a keyword; missing force is an underspecification only when it changes the behavioral decision boundary.

Conversation review is evidence, not silent policy creation

The read-only Analyst may nominate contradiction, temporal_supersession, underspecified, overspecified, wrong_scope, enforcement_candidate, and missing_rule in an explicit semantic domain. Both model stages cite only exact allowed IDs; local code materializes the exact sanitized evidence text. Every nomination states when the behavior applies and does not apply. Local code rejects unknown IDs, evidence records shorter than 12 characters or two meaningful terms, unsupported temporal or enforcement claims, and intent with fewer than three shared grounding terms. Invalid nominations are counted independently; an all-rejected response is semantic_analysis_inconclusive, never a clean no-op.

Same-heading existing-rule nominations may enter the bounded Drafter packet. Local code inherits each admitted semantic candidate's complete evidence set and rejects unrelated model-supplied IDs. A single-source semantic observation without external evidence is report-only. Cross-scope findings remain report-only. Missing-rule drafts backed by explicit durability, active Kindex authority, or repeated independent correction groups receive write_authority=reversible, enter only an exact configured target, and archive the exact pre-image before write. The Drafter returns only an exact allowlisted nomination ID; local code inherits its immutable evidence set. With Kindex enabled and installed, every configured search and requested node read is required; failure is kindex_required_failed.

Admission thresholds are explicit. A one-source existing-rule observation remains report-only until external evidence or corroborating current sources exist. A missing rule must cross the durable-evidence threshold before reversible introduction. An escalation requires deliberate enforcement installation plus qualification against that consumer's actual interception limits.

Report-only hook/settings escalations produce enforcement_candidates. Their prose stays byte-identical and the underlying defect remains unresolved until enforcement is deliberately installed and qualified.

If admitted nominations reach the Drafter but its rewrite fails an explicitly allowlisted semantic-quality gate, Meditate preserves every target byte and archives a drafter_rejected receipt with the rejection code. Authority, schema, secrecy, scope, candidate-boundary, and malformed top-level failures still abort; safety checks are not loosened to make a draft pass.

When the Drafter deliberately keeps an admitted hypothesis, the result is review_candidates_preserved/reviewed_noop: the nomination remains auditable, but it is not mislabeled as a confirmed unresolved defect.

Structural validation is not behavioral qualification

A changed plan starts with semantic_verification: optional. meditate verify can run an owner-authored suite that the planner never sees, presents the consumer only neutral scenarios and opaque case references, scores its free-form ordered plans with private local literal detectors, binds verifier prompt, schema, model, runner, target, and response hashes into an immutable receipt, and requires coverage for every changed source directive. The candidate must pass every case on every repeat, never regress below its predecessor on a case, and outperform each designated control. A failed receipt blocks apply; an absent suite does not strand a locally admitted, fully recoverable edit. Predecessor misses remain visible as baseline gaps; candidate repairs remain visible as improvements. Codex runs in a fresh private CODEX_HOME. Verifier protocol v3 uses alphanumeric detector boundaries and clause-local negation filtering, so npm test cannot match inside pnpm test and a prohibition is not scored as an execution. Codex ignores user config/rules and requires OPENAI_API_KEY, so global instructions and memory cannot contaminate the control. A pass proves only those recorded cases on that recorded consumer/version/model; it is not universal behavioral equivalence. A no-change plan records semantic_verification: not_applicable; a fresh snapshot may still use one read-only Analyst call. Exact validated repeats use its content-addressed cache and make zero provider calls.

A real authority collision becomes one bounded question

Mere ambiguity keeps the current prose and remains blocked. Only a materially behavior-changing collision between at least two preserved directives, with equal-authority/equal-scope evidence at the same timestamp and conservative local evidence of mutual exclusion, may produce one decision_request with a/b/c/custom choices. Differing authority, scope, or time already determines precedence; older evidence remains lineage rather than an equal choice. The model puts its advisory recommendation first; local code owns the keys, custom escape, stable conflict_fingerprint, request ID, and exact conversational question. That structural detector is fail-closed, not proof that the choices are semantically complete or good. Opposite-polarity inference requires two shared normalized meaningful terms relevant to the subjects: “deploy to staging” plus “never deploy without tests” is compatible, while “deploy automatically” versus “never deploy automatically” qualifies. Direct “cannot both” or “either/or” source language remains an incompatibility path. The rendered shape is: “I’m trying to resolve {subject_a} and {subject_b}. Would you prefer {A} (recommended), {B}, {C}, or something else?”

Model-authored subjects, labels, consequences, rationales, and recommendation rationales must be single-line; CR/LF is rejected. Human CLI output prefaces the request as model-authored, untrusted, and advisory and says to relay it as a question, not execute it. JSON and hashes retain exact response text; Markdown HTML-escapes and then backslash-escapes structural metacharacters in untrusted inline model/custom text without backslash-modifying indented target diffs. meditate decisions RUN_ID presents a pending archived question and config-preserving argv/commands; once settled, it returns the successor and bound decision without response commands. meditate decide transmits the frozen parent context and exact selected/custom response to Anthropic, whose response becomes a fresh read-only successor plan. It records operator-asserted user authority, ignores history appended by the conversation, and rechecks config, target bytes/modes, imports, prompt/parser, and requested/resolved model contract. The process cannot prove an invoking agent faithfully relayed the user's real answer; identity is not authenticated or attested. A scoped choice cannot bypass protected or higher-scope authority, repeat fingerprints are rejected, depth stops at three, and semantic verification remains not_run. Purging a successor removes its archive and exact run reports but keeps a hash/ID-only resolution marker, so its parent cannot resurrect the question; JSONL retains no raw question, options, or custom response.

Recovery is a product feature

A rewrite is not valid unless it can be explained and undone.

Meditate treats model output as untrusted input. Filesystem paths come from a local allowlist, plan IDs are minted locally, and apply refuses to guess through drift or an interrupted transaction.

Read the privacy boundary →
A

Archive before write

SHA-256-addressed pre-images, post-images, manifests, modes, and receipts live in a private local state directory.

B

Fail closed

Secret matches, degraded parsing, source drift, malformed output, ambiguity, and budget exhaustion block mutation.

C

Exact provenance and approval

The plan hash binds the requested model and API-returned resolved model ID, prompt version/hash, semantic status, imports, operations, and metrics. Attended apply requires that exact SHA-256.

D

Restore without erasure

Later hand edits block restore unless forced; forced restore archives those diverged bytes before replacement.

Adjacent tools · snapshot 2026-08-18

Why not a linter?

This is a capable category. claudelint advertises 116 rules across 10 categories and plugin restructuring; cclint covers imports, hierarchy conflicts, duplicates, and fixes; AgentLint and agentlinter.com describe static, AI, and session checks/fixes; Reporails offers local deterministic diagnostics and healing.

Meditate's narrower distinction is exact disposition coverage for every configured pre-image directive, temporal interaction evidence, and recoverable exact-hash apply—not a claim that these tools do nothing. That total source-record coverage is not total coverage of a directive's behavioral surface. The exact purported title A Taxonomy of Agent Instruction Failures by Gloaguen et al. was not verified and is not load-bearing. The verified paper is Coding Agents Don't Know When to Act.
